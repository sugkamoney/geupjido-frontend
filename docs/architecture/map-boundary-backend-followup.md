# BE 추가 요청: 지도 표시 경계의 한강 수면 제외

> 상태: 추가 전달용 초안·미발송 · 버전: 0.1 · 갱신: 2026-11-15

## 요청 배경

사용자가 이미 전달한 [단지 좌표·권역 면적 요청](map-api-backend-request.md)과 별개의 추가 항목입니다.
이번 추가 요청은 아직 발송하지 않았습니다. 현재 지도 제품 요구사항은 선택 권역 면의 한강 제외입니다.

## FE에서 확인한 결과

- `GET /api/v1/map/zones/gangnam-apgujeong` 응답: 외곽 ring 1개·hole 0개·좌표 200개.
- FE SVG도 점 200개·subpath 1개이며 독립 NAVER GL projection과 최대 차이 0 CSS px였습니다.
- 실제 NAVER 지도에서 한강 위로 보이는 `(경도 127.040000, 위도 37.532000)` 지점이
  응답 geometry와 SVG 채움 모두에 포함됐습니다. 원본 좌표를 FE가 임의 확장한 현상은 아닙니다.
- BE `a3e7a28` 사본은 압구정동 `1168011000` 경계를 union하며 수면 제외 처리를 하지 않습니다.
  실제 배포 빌드·원본 적재 날짜·공인 수계 교차 면적은 FE에서 확인하지 않았습니다.

## 확인·보완 요청

1. 서비스 DB polygon과 실제 적재한 VWorld 원본 `emd_cd=11680110`의 경계·수집 시점을 대조해 주세요.
2. 위 한강 표본의 `ST_Covers`와 공인 수계의 교차 영역을 확인해 주세요.
3. 지도 표시 geometry에서 한강 수면을 제외해 주세요. 다른 강변 권역에도 같은 조건을 점검해 주세요.
4. 단지 소속 판정·viewport 조회에 쓰는 경계와 화면 표시 경계를 분리할지 검토해 주세요.
   수면 제외를 위해 단지 배정과 권역 소속이 의도치 않게 달라지지 않아야 합니다.
5. 면적 제공 요청의 area가 표시 경계 기준인지 판정 경계 기준인지 계약에 명시해 주세요.
6. 보완 후에도 WGS84 Polygon/MultiPolygon의 여러 면과 hole을 유지하고, 전체 단지 목록·ID·급지·순위 계약은 보존해 주세요.

## 완료 확인 기준

압구정 상세의 한강 수면이 선택 면에서 채워지지 않고, 실제 주거 지역과 단지 위치는 정상적으로
유지돼야 합니다. FE는 응답 geometry를 그대로 사용하므로 위도 고정 절단이나 임의 축소는 하지 않습니다.
정상 수면 제외·외부 대조점·단지 대조점과 다른 강변 권역의 회귀 근거를 함께 제공해 주세요.
