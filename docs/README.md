# 급지도 프론트엔드 문서

이 디렉터리는 현재 제품 동작, 프론트엔드 구조, 프로젝트 맥락의 기술 학습,
그리고 중요한 결정의 이유를 코드와 같은 Git 이력으로 관리한다.

## 문서 분류

- `product/`: 현재 유효한 화면 동작, UX 규칙, 반응형 동작, 브라우저 지원 정책
- `architecture/`: 컴포넌트 경계, 라우팅, 상태와 데이터 흐름, API 연동,
  스타일링, 테스트, 빌드 및 배포 구조
- `learning/`: 프론트엔드 개념과 기술을 이 프로젝트에 적용하는 맥락으로 설명
- `history/`: 중요한 제품·기술 결정, 검토한 대안, trade-off와 재검토 조건

현재 기준과 과거 판단을 구분한다. 현재 제품 동작은 `product/`가 소유하고,
현재 기술 구조는 `architecture/`가 소유한다. `history/`는 결정 당시의 이유를
보존하지만 현재 동작이나 구조의 기준을 대신하지 않는다.

## 작성 원칙

1. 사용자에게 보이는 동작이나 UX 정책이 바뀌면 관련 `product/` 문서를
   갱신한다.
2. 컴포넌트 경계, 데이터 흐름, 외부 연동, 테스트 또는 배포 구조가 바뀌면
   관련 `architecture/` 문서를 갱신한다.
3. 새 프론트엔드 개념이나 기술을 학습하면 일반 개념과 이 프로젝트의 적용
   방식을 함께 `learning/`에 설명한다.
4. 중요한 선택에는 대안, 이유, trade-off와 재검토 조건을 포함해
   `history/`에 기록한다.
5. 웹을 우선하되 작은 화면에서 동작이 달라지는 기능은 모바일 웹 지원,
   제한 또는 연기 여부를 명시한다.
6. 포맷팅, 이름 변경, 명백한 오타처럼 기계적이고 자명한 변경은 별도의
   history 문서를 만들지 않는다.
7. 비밀값, 접근 토큰, 개인 사용자 데이터, 민감한 배포 정보는 문서에
   커밋하지 않는다.

## 문서 상태

필요한 경우 문서 상단에 다음 상태를 표시한다.

- **제안**: 방향을 검토 중이며 아직 구현 기준이 아니다.
- **확정**: 현재 제품 또는 구현의 기준이다.
- **대체됨**: 더 이상 현재 기준이 아니며 대체 문서를 함께 연결한다.
