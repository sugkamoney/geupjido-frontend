# ADR-004: 데스크톱과 모바일 웹을 함께 지원한다

> 상태: **확정** · 날짜: 2026-10-13 · 영역: **제품·프론트엔드**

## 맥락

ADR-002는 초기 지원을 데스크톱 웹으로 제한했다. 디자인 핸드오프에 모바일 HTML과
데스크톱 대비 차이를 설명한 MD가 추가됐고, 사용자가 모바일 지원을 확정했다.

## 결정

데스크톱과 모바일 웹을 제품·QA 범위에 포함한다. React·TypeScript·Vite SPA와
NAVER Maps 선택은 유지한다. 모바일 디자인 자료는 참고용이라는 디자이너의
전달 조건도 유지하며 세부 배치, 최소 viewport와 브라우저 범위는 추가 확정한다.

## 이유와 trade-off

사용자가 확정한 제품 범위를 반영한다. 모바일에서 지도·상세·검색·월드컵을
사용할 수 있도록 터치 입력과 작은 화면에 맞춘 배치가 필요하다. 화면·입력 방식별
구현 및 검증 비용이 늘어나며 데스크톱 고정 폭 화면을 단순 축소해 대체할 수 없다.

## 후속 작업

[플랫폼 지원 범위](../product/platform-support.md)를 현재 정책으로 사용한다.
프로젝트 초기화부터 모바일 대응을 고려하고, 화면 구현 전 참고 시안의 미정
항목과 작은 화면 UX를 확인한다.
