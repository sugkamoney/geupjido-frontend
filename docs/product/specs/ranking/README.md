# 랭킹

> 상태 · 탐색 연결 및 테스트 셸 검증 / 버전 · 0.2 / 갱신 · 2026-11-27

지도 사용자가 수도권 권역을 지역과 급지로 좁혀 현재 순위와 최근 급지 변동을 확인하고 관심 권역을 선택한다. 데스크톱 랭킹 패널과 모바일 웹의 좁은 폭에서도 쓸 수 있는 패널 콘텐츠를 다룬다. 권역을 선택하면 지도와 권역 상세로 이어진다. 셸과 결합한 진입·닫기·지도 복귀는 브라우저 검증을 앞두고 있다.
