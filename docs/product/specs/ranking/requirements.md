# 랭킹 요구사항

> 상태 · 패널 기준 / 버전 · 0.1 / 갱신 · 2026-11-27

## 조회와 선택

- 처음에는 전체 지역의 1급지를 민심 급지 순으로 본다. 지역은 전체, 서울, 경기·인천 중 선택한다.
- 급지 탭은 1~5급지와 모으는 중으로 구성한다. 탭에 선택 지역의 권역 수를 표시한다. 현재 탭 이외의 0개 탭은 비활성화한다. 집계 전에는 수를 대시로 표시한다.
- 급지 탭에서 민심 급지 순, 많이 오른 곳, 많이 내린 곳을 고를 수 있다. 모으는 중으로 이동하면 기본 정렬로 돌아가며 정렬 칩을 숨긴다. 지역 선택은 계속 사용할 수 있다.
- 표시 이름과 순서, 지역 범위 내 순위는 공개 랭킹과 일치한다. 정렬을 바꿔도 각 권역의 순위 숫자는 유지한다. 순위와 급지가 미정인 항목은 대시로 표시한다.
- 급지 변동은 직전 성공 발표와 비교해 방향과 폭을 표시한다. 변동이 없거나 비교할 수 없는 경우는 대시로 표시한다. 직전 발표가 있고 당시 비교 급지가 비어 있던 권역이 현재 급지를 받으면 새로 표시한다.
- 모으는 중에는 권역 유효표, 참여자, 권역 간 유효표 수를 각각 표시한다. 전환 목표는 50표, 10명, 20표다. 세 조건을 충족한 권역은 성공 발표에서 민심 급지로 전환된다.
- 최근 성공 발표 시각은 한국 시간으로 표시한다. 발표 전에는 아직 발표된 랭킹이 없다고 안내한다.
- 조회 중, 결과 없음, 조회 실패를 구분한다. 실패 안내에서 다시 시도할 수 있다. 권역 행은 클릭, 터치 또는 키보드로 선택할 수 있다.

## 웹 지원

데스크톱 패널은 Figma의 390px 구성을 따른다. 좁은 모바일 웹에서는 패널 폭에 맞춰 필터를 줄바꿈하고 권역 목록을 세로 스크롤한다. 모바일 진입·닫기·지도 복귀 동선은 앱 셸 통합 시 확정한다.
