# 랭킹 인수 기준

> 상태 · 패널 픽스처 기준 / 버전 · 0.1 / 갱신 · 2026-11-27

| 조건 | 기대 결과 |
| --- | --- |
| 전체 지역 1급지의 기본 화면을 연다 | 1급지와 민심 급지 순이 선택된다. 급지 탭 6개의 권역 수가 표시된다. |
| 지역 또는 정렬을 바꾼다 | 새 조건의 결과가 표시되고 행 이름·순서·순위가 응답과 일치한다. |
| 상승 정렬에서 모으는 중을 고른다 | 상승·하락 칩이 사라지고 지역을 바꿀 수 있다. 행마다 50표, 10명, 20표 기준이 각각 표시된다. |
| 순위·급지가 없는 권역을 연다 | 순위와 급지는 대시로 표시하고, 보조 기술에는 미정으로 안내한다. |
| 조회가 진행되거나 성공 목록이 비어 있다 | 조회 중과 결과 없음 안내가 각각 표시된다. |
| 조회에 실패하고 다시 시도한다 | 실패 안내와 다시 시도 버튼이 표시되고, 버튼을 누르면 조회가 재개된다. |
| 권역 행을 Enter 또는 터치로 선택한다 | 해당 권역의 선택이 전달된다. |
| 데스크톱 390px와 모바일 웹 320px에서 목록을 확인한다 | 데스크톱에서는 필터가 한 줄에 표시된다. 좁은 폭에서는 필터가 줄바꿈되고 가로 넘침 없이 권역 목록을 세로로 탐색한다. |
