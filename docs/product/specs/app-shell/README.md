# 앱 화면 틀

> 상태: 검토용 구현·검증 완료 · 버전: 0.2 · 최종 변경: 2026-10-13

사용자가 지도 탐색과 비교 기능을 사용할 화면의 자리와 이동 경로를 준비한다.
대상은 데스크톱·모바일 웹 사용자이며 모바일도 정식 지원 범위다.
이 사이클은 디자인 시스템 PR #2가 develop `2c3a1f4`에 병합된 후 시작했다.

범위는 레일/하단 탭, 왼쪽 패널 접기·복원, 상세 패널/아래 시트,
검색 배치, 구/권역 전환과 지도 조작의 자리다. API·실제 지도·검색 결과와
정렬·대진/투표/비율/급지 집계는 후속 범위다. 실제 지표를 임의로 표시하지 않는다.

홈은 데이터 연결 전 준비 상태다. `/app-shell`은 명시적인 검토 화면이며
fixture는 실제 지역·단지·수치와 구분한다. 랭킹·리포트는 검토 화면에서만
비활성 표시한다(2026-10-13 사용자 답변). 제품 노출 정책은 미정이다.
