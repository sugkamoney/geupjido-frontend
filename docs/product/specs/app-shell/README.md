# 앱 화면 틀

> 상태: PR #3 통합 완료 · PR #4 모바일 보완 검증 · 버전: 0.4 · 최종 변경: 2026-10-14

사용자가 지도 탐색과 비교 기능을 사용할 화면의 자리와 이동 경로를 준비한다.
대상은 데스크톱·모바일 웹 사용자이며 모바일도 정식 지원 범위다.
이 사이클은 디자인 시스템 PR #2가 develop `2c3a1f4`에 병합된 후 시작했다.

범위는 레일/하단 탭, 왼쪽 패널 접기·복원, 상세 패널/아래 시트,
검색 배치, 구/권역 전환과 지도 조작의 자리다. API·실제 지도·검색 결과와
정렬·대진/투표/비율/급지 집계는 후속 범위다. 실제 지표를 임의로 표시하지 않는다.

홈과 `/map-exploration`의 지도 경험은 [지도 탐색 SDD](../map-exploration/README.md)에서 관리한다. 현재는 명시적인 지도 검토용 데이터다. `/app-shell`은 화면 틀의 별도 검토 화면이며 fixture는 실제 데이터와 구분한다. 랭킹·리포트는 검토 화면에서만
비활성 표시한다(2026-10-13 사용자 답변). 제품 노출 정책은 미정이다.

- [요구사항](requirements.md), [완료 조건](acceptance-criteria.md), [결정](decisions.md)
- [기술 구조와 계획](../../../architecture/app-shell.md)
- [디자인 핸드오프](../../design-handoff.md), [플랫폼 지원](../../platform-support.md)
- [Figma 메인](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU?node-id=594-21211)
- 관련 Notion: 이 사이클에 연결된 문서 없음. 저장소 문서가 현재 작업 기준.

## 지도 상세 모바일 보완

접힌 시트의 선택 단지 행은 요약 스크롤 밖에서 계속 접근할 수 있다. 키보드 목록 선택으로 시트가 접히면 선택 행으로 focus를 복귀한다. 짧은 화면의 펼친 시트는 요약·목록을 각각 스크롤하고 목록 제목을 유지한다. 최소 지원 화면/OS와 시트 배치는 후속 디자인·실기기 리뷰 대상이다. [지도 수용 기준](../map-exploration/acceptance-criteria.md)과 [기술 검증](../../../architecture/map-exploration.md#pr-4-전체-코드리뷰-보완)을 따른다.
