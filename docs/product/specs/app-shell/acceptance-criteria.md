|---|---|---|
| AS-01 | 홈과 검토 화면 직접 방문 | API/지도키 없이 표시, 미정 메뉴는 `/app-shell`에만 표시. 홈 지도 검토 데이터는 지도 탐색 SDD를 따름 |

| AS-05 | 긴 목록을 휠·터치·키보드 스크롤 | 해당 목록만 이동, 머리·검색·지도·바깥 문서 유지 |
| AS-06 | 모바일에서 상세 펼침/접기 | 버튼/터치 손잡이 사용 가능, 목록 스크롤과 구분 |
| AS-07 | 모바일 검색 진입/닫기/Escape | 전체 편집 영역, focus 진입·복귀, 검색어 유지·지우기 가능 |
| AS-08 | 1280/1440·320 스트레스·가로 방향·긴 문구 | 가로 넘침 없음, 닫기·전환·검색에 접근 가능 |
| AS-09 | Tab/Enter/터치 | 보이는 focus, 조작 상태 ARIA 제공, 터치 목표 확보 |
| AS-10 | SDK 미연결 | 지도 조작 비활성, 실제 지도 동작이나 집계/검색 결과를 주장하지 않음 |

320px 및 브라우저 에뮬레이션 크기는 검사 입력이며 최소 지원 정책이 아니다.
실제 기기 가상 키보드/VoiceOver와 운영 지도는 이번 자동 검증으로 대체하지 않는다.
실행 명령·기대/실제 결과와 미실행 사유는 [기술 검증 기록](../../../architecture/app-shell.md)에 둔다.
