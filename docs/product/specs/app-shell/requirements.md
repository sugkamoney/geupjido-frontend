# 요구사항

> 상태: 검토용 구현·검증 완료 · 버전: 0.2 · 최종 변경: 2026-10-13

## 데스크톱

- 레일에는 지도와 월드컵이 있다. 도움말은 숨긴다. 익명 아바타는 계정 기능을 제공하지 않는다.
- 월드컵 메뉴는 왼쪽 타임라인 패널을 연다. 손잡이로 접고 마지막 패널을 복원한다.
  처음 복원하는 패널은 월드컵이다. 접힌 콘텐츠는 Tab 탐색 대상에서 빠진다.
- 1920×1080 기준 레일 64, 왼쪽 패널 390, 상세 360, 검색 340px.
  상세는 위아래 16px, 왼쪽 패널이 열리면 x=476, 닫히면 x=76.
  검색은 상세 오른쪽 8px, 패널만 열리면 패널 오른쪽 16px,
  둘 다 닫히면 x=80. 구/권역 전환은 검색 오른쪽 8px.
- 지도는 레일 오른쪽 전체 영역이며 패널은 그 위에 뜬다. 지도 → 라벨/핀 →
  검색·지도 조작 → 패널/상세 → 검색 결과 → 딤/모달 순서다.
- 왼쪽 패널 머리·시작 구역과 목록 제목은 고정하고 목록만 스크롤한다.
  상세 머리·요약·목록 제목도 고정하고 목록만 스크롤한다.
- 상세는 닫기로 선택을 해제한다. 닫힌 뒤 선택을 열었던 요소로 focus가 돌아간다.
  상세가 열리면 권역이 선택 상태이며 구를 누르면 상세를 닫고 구로 전환한다.
- 지도 SDK 연결 전 조작 버튼은 비활성이며 실제 이동·zoom을 수행하지 않는다.
  검색 입력·지우기는 가능하나 결과·정렬·검색 성공을 가장하지 않는다.

## 모바일 웹

- 레일 대신 하단 탭, 위 검색과 아래 구/권역 전환, 상세는 아래 시트로 준비한다.
- 확대·축소 버튼은 숨기고 전체 보기 자리를 둔다. 터치 제스처의 실제 지도 동작은 후속이다.
- 시트는 접기/펼치기 버튼과 터치 손잡이로 조절 가능하며 목록만 스크롤한다.
  키보드로도 같은 상태를 조절한다. 닫기는 선택 해제와 focus 복귀를 제공한다.
- 검색은 입력을 누르면 화면 전체 편집 영역으로 전환한다. 닫기/Escape는 검색 자리로
  돌아가며 입력값은 유지된다. 실제 검색 결과는 후속이다.
- 월드컵 탭은 모바일 타임라인을 열지 않는다. 이번 범위에서는 준비 안내를 표시한다.
- 긴 문구와 작은 화면에서 가로 넘침 없이 조작하고 짧아진 화면 높이를 수용한다.

## 검토용 배치와 경계

모바일·좁은 데스크톱 배치는 사용자 답변에 따라 **검토용 임시 배치**로 구현한다.
최소 지원 viewport, breakpoint, 시트 높이는 확정 제품 정책이 아니다.
1280/1440에서는 상세와 검색을 함께 사용할 수 있도록 검색 폭/줄 배치를 검토한다.
랭킹·리포트는 검토 화면에서만 비활성 표시하며 홈에서는 노출하지 않는다.
fixture 검토에서 수치·단계·표·지역 정보를 확정 제품 데이터로 표시하지 않는다.
색상은 Figma 원본을 유지하고 WCAG 대비 준수를 주장하지 않는다.
