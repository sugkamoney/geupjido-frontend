# 검색 인수 기준

> 상태: 검토용 구현·검증 완료, 실제 연동 대기 · 버전: 0.1 · 갱신: 2026-10-14

1. `강 남 구 압`은 구+권역으로 압구정을 찾으며 조합 중 입력도 결과를 갱신한다. 공백만 입력하면 결과가 없다.
2. 영문 대소문자/공백 차이가 같은 대상을 찾고 원문 공백·글자를 유지하며 일치한 글자만 굵어진다.
3. 권역/구/단지는 5/3/6개 이내이고 빈 그룹은 없으며 위치·길이·동률 정책 순서가 재현 가능하다.
4. 없는 이름은 지정 문구를 표시한다. ArrowDown/Up은 끝에서 순환하고 Enter는 첫/활성 항목을 선택한다. 조합 확정 Enter와 keyCode 229는 선택하지 않는다.
5. 첫 Escape는 결과만 닫고 두 번째는 입력을 벗어난다. 지우기 후 focus가 입력에 있으며 선택/상세 닫기 뒤 focus를 안정적으로 복원한다.
6. 구·권역·단지를 선택하면 기존 지도 카메라·상세·목록 선택이 일치하며 화면 밖 단지 검색도 성공한다. 새 지도 입력은 카메라 이동을 중단한다.
7. 모바일 전체 검색에서 터치/키보드로 선택하면 닫히며 짧은 화면의 스크롤·지우기·닫기가 작동한다. 기존 지도·시트 gesture/키보드 회귀가 통과한다.

검토용 소스 기준 인수 시나리오를 통과했다. 단위·통합 55개, 데스크톱/모바일 브라우저 73개 통과(23개 플랫폼 적용 제외)다. 실제 제품 API·NAVER SDK·물리 기기 소프트 키보드/VoiceOver 검증은 대기다.

실행 명령·기대/실제와 미실행 사유는 [검증 기록](../../../architecture/search.md)에 기록한다.
