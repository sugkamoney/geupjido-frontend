| 확정 | 검색을 지도·권역 상세와 함께 첫 BE 연동 범위에 포함한다 | 2026-11-15 사용자 동의 / [계약 조사](../../../architecture/map-api-integration-review.md)의 서버 정렬·80자 제한을 적용했고 BE 계약 변경 때 재검토 |

| 구현 결정 | 결과 바깥 focus 이동은 닫고 입력/재진입/방향키는 다시 연다                          | 기존 검색 슬롯·combobox 일관성 / 디자인 리뷰                               |
| 구현 | 실제 검색 데이터·초기 급지·구별 권역 수 연결, 입력 최대 80자 | 현재 BE 검색 응답 / BE 계약 변경 때 |
| 대기      | 모바일 최소 viewport/브라우저, 실기기 키보드/VoiceOver                              | 모바일 지원은 확정, 참고 시안·preset은 최솟값이 아님 / 실기기 QA·제품 리뷰 |


현재 기본 지도 화면은 실제 API를 사용하고 예시 화면은 `/map-exploration/fixtures`로 분리한다.
연동 범위·임시 동작과 검증 한계는 [실제 화면 연결 구조](../../../architecture/map-api-ui-integration.md)를 따른다.
