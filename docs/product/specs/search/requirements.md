# 검색 요구사항

> 상태: 검토용 구현·검증 완료, 실제 연동 대기 · 버전: 0.1 · 갱신: 2026-10-14

입력할 때마다 한글 조합 중에도 검색한다. 공백을 제거하고 대소문자를 무시한 부분 일치다. 권역은 권역 이름 또는 구+권역, 구는 전체 이름 또는 끝의 구/시를 뺀 이름, 단지는 이름을 검색한다. 빈 문자열/공백만 있으면 결과·추천·결과 없음 안내를 표시하지 않는다.

권역 → 구 → 단지 순서로 묶고 각각 최대 5/3/6개를 표시한다. 빈 그룹은 숨긴다. 그룹 안에서 일치 위치가 빠른 순, 이름이 짧은 순으로 정렬한다. 두 기준이 같은 항목은 고유 ID의 오름차순으로 순서를 고정한다. 원문에서 일치한 글자를 굵게 표시한다.

결과 없음 문구는 `'{입력값}'에 맞는 권역 · 구 · 단지가 없습니다`이다. ↓/↑는 전체 표시 결과를 순환하고 Enter는 활성 항목 또는 첫 항목을 선택한다. IME 확정 Enter는 선택하지 않는다. Escape는 열린 결과를 먼저 닫고, 이미 닫혀 있으면 입력을 벗어난다. 다시 입력/방향키/검색창 재진입하면 결과를 연다. 입력 바깥으로 이동하면 결과를 닫는다. 지우기는 기존 검색창의 입력 focus를 유지한다.

선택 시 결과를 닫고 선택 이름을 넣는다. 권역은 기존 지도 선택·상세 열기, 구는 경계에 맞추기, 단지는 해당 권역 상세와 단지 목록을 선택하고 단지 중심·zoom max(현재,15)로 이동한다. 현재 viewport 밖 대상도 검색한다.

모바일은 기존 전체 화면 검색을 사용하고 선택하면 전체 검색을 닫는다. 결과만 스크롤하며 짧은 화면에서도 입력·닫기에 접근한다. 터치 스크롤을 선택으로 오인하지 않는다. 키보드·pointer/touch·가시적 focus·스크린리더 활성 결과를 지원한다. 지원 최소 크기/OS/브라우저 버전은 [플랫폼 정책](../../platform-support.md)의 미정 상태를 유지한다. 구현 breakpoint/device preset은 검토 기준이다.

검색 확인 중에는 `검색 중이에요.`를 표시한다. 조회 실패는 결과 없음으로 표시하지 않고 `검색을 불러오지 못했어요.`와 `다시 검색`을 제공한다. 재시도는 입력으로 focus를 복원한다.

데이터 계약·상태·오류·검증 방식은 [검색 구조](../../../architecture/search.md)를 따른다.
