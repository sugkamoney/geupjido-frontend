# 지도 탐색

> 상태: 제안
> 현재 버전: v0.2
> 최종 변경: 2026-10-13
> 관련 Notion: [서비스 기획안](https://app.notion.com/p/9564038ee1da8376a998011ae64b138c?pvs=204)

## 목표

사용자가 지도에서 시군구, 생활권 권역, 아파트 단지를 순서대로 탐색해 관심
위치의 범위와 주변 단지를 이해하도록 한다.

## 대상 사용자

서울·경기 생활권의 급지와 아파트 단지를 지도에서 비교하려는 데스크톱·모바일 웹
사용자다.

## 범위

### 포함

- 시군구와 생활권 권역 경계를 지도에서 탐색
- 확대 수준에 따른 단지 군집과 개별 단지 탐색
- cluster 선택 시 해당 위치를 중심으로 zoom을 2단계 높이는 지도 이동·확대
- 단지 결과 없음, 결과 제한, 지도 로딩·조회 실패의 사용자 안내

### 제외

- 급지 월드컵, 랭킹, 커뮤니티, 관심 권역 저장
- 권역·개별 단지의 상세 정보와 상세 화면 진입 방식
- 시세·민심 급지 전환, 지역·평형·연차 필터, 통합 검색, 공유 URL의 제품 정책

제외 항목 중 지도 탐색에 직접 관련된 미결 정책은
[제품 결정](decisions.md)에서 관리한다.

## 최신 핸드오프와의 관계

새 [디자인 핸드오프](../../design-handoff.md)가 라벨·단지 핀, 상세·검색 동작을
구체화했다. 이 문서의 기존 cluster·zoom·상세/검색 미정 기록은 9월 제안이며 새
핸드오프와 충돌한다. 다음 지도 구현 전 SDD 요구사항·수용 기준을 새 디자인과
API 계약에 맞춰 갱신한다. 모바일 지원 정책은 이번 갱신으로 반영했다.
