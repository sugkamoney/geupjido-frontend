# 지도 탐색

> 상태: 실제 NAVER 지도 연결·자동 검증 완료 · 모바일 실기기·실제 데이터 대기
> 현재 버전: v0.8
> 최종 변경: 2026-10-27

## 목표와 대상

서울·경기 생활권을 살펴보는 데스크톱·모바일 웹 사용자가 구 → 권역 → 단지를 탐색하고 선택 상세와 위치를 연결한다.

## 범위

구·권역 라벨, 단지 핀, 선택 권역 면, 확대/축소/전체 보기, 구/권역 전환, 권역 상세·단지 목록 선택/해제를 포함한다. 독립 검색 결과 알고리즘, 월드컵 대진·투표·집계, 필터와 공유 URL은 후속이다.

실제 NAVER 지도(GL) 위에 검토용 WGS84 좌표의 라벨·핀·선택 면을 올려 동작을 검증한다. 데이터는 계속 검토용이며 실제 경계·거래가·민심 집계 연결은 별도로 추적한다. 지도를 불러오지 못하면 가상 grid로 대체하지 않고 안내와 재시도를 보인다.

검토용 데이터 범위는 서울 25개 구(권역 132곳)와 경기·인천 10개 묶음(권역 31곳), 단지 700여 개다. 위치는 대략 값이며 실제 경계·시세·집계가 아니다. 상세는 [기술 문서](../../../architecture/map-exploration.md)의 검토용 데이터 절을 따른다.
