# 지도 탐색

> 상태: 실제 API 화면 연결 · BE 보완·실제 SDK 결합·모바일 실기기 검증 별도
> 현재 버전: v0.9
> 최종 변경: 2026-11-15

## 목표와 대상

서울·경기 생활권을 살펴보는 데스크톱·모바일 웹 사용자가 구 → 권역 → 단지를 탐색하고 선택 상세와 위치를 연결한다.

## 범위

구·권역 라벨, 단지 핀, 선택 권역 면, 확대/축소/전체 보기, 구/권역 전환, 권역 상세·단지 목록 선택/해제를 포함한다. 월드컵 대진·투표·집계, 상태 카드·랭킹·리포트, 필터와 공유 URL은 후속이다.

기본 지도·검색·권역 상세는 실제 서비스 데이터를 사용한다. 초기 급지를 기본으로 표시하고
대표 거래가·단지 순위·선택 경계를 실제 응답에 맞춘다. 상태 카드·랭킹·투표함·월드컵 API는 후속이다.
BE 보완 전 면적 없는 라벨과 좌표 미확보 단지의 임시 동작은 요구사항과 결정을 따른다.
지도 바탕은 NAVER GL이며 키 없는 명시적 로컬 검토 모드만 grid adapter를 사용한다.

## PR 리뷰 보완

PR #4 전체 리뷰의 중요 문제 5건을 수정했다. 작은 화면의 목록·선택 행 접근성과 최신 상세 표시를 보완했으며 당시 실제 SDK/API 연결은 별도 대기였고 현재는 NAVER 지도가 연결됐다(제품 API는 대기). 재현과 검증 결과는 [기술 문서](../../../architecture/map-exploration.md#pr-4-전체-코드리뷰-보완)를 따른다.


현재 기본 지도 화면은 실제 API를 사용하고 예시 화면은 `/map-exploration/fixtures`로 분리한다.
연동 범위·임시 동작과 검증 한계는 [실제 화면 연결 구조](../../../architecture/map-api-ui-integration.md)를 따른다.
