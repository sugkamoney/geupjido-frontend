# 지도 탐색

> 상태: 검토용 UI 구현·검증 완료 · 실제 지도·데이터 연결 대기
> 현재 버전: v0.4
> 최종 변경: 2026-10-14

## 목표와 대상

서울·경기 생활권을 살펴보는 데스크톱·모바일 웹 사용자가 구 → 권역 → 단지를 탐색하고 선택 상세와 위치를 연결한다.

## 범위

구·권역 라벨, 단지 핀, 선택 권역 면, 확대/축소/전체 보기, 구/권역 전환, 권역 상세·단지 목록 선택/해제를 포함한다. 독립 검색 결과 알고리즘, 월드컵 대진·투표·집계, 필터와 공유 URL은 후속이다.

현재 구현 단계는 명시적인 검토용 지도·데이터로 동작을 검증한다. 실제 NAVER 지도·거래가·민심 집계 연결은 완료 조건으로 별도 추적한다.
