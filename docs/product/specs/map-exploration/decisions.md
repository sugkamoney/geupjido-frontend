## 미결 결정

| 질문 | 현재 상태 | 다음 검토 조건 |
| --- | --- | --- |
| 결과 제한 시 다음 행동은 무엇인가 | 확대 안내, cluster 재전환, 목록 제공 중 미정 | 실제 결과 제한 사례와 화면 디자인을 검토하고 제품 정책 확정 |
| 권역·개별 단지의 상세 정보와 진입 방식은 무엇인가 | 표시 필드와 화면 또는 패널 진입 방식이 미정 | 데이터 계약과 Figma 화면 구성이 확정 |
| 시세·민심 급지는 지도에서 어떻게 노출하고 전환하는가 | 기본 기준과 전환 UI가 미정 | 급지 산출·표본 정책과 화면 디자인이 확정 |
| 지역·평형·연차 필터를 초기 출시에서 제공하는가 | 필터 조합과 기본값이 미정 | 데이터 가용성과 필터 UX가 확정 |
| 통합 검색의 대상과 결과 동작은 무엇인가 | 시군구·권역·단지의 검색 범위와 선택 동작이 미정 | 검색 API 계약과 화면 디자인이 확정 |
| 공유 URL에 어떤 지도 상태를 보존하는가 | 위치·확대 수준·필터·선택 상태의 공개 규칙이 미정 | URL 상태와 개인정보·공유 정책이 확정 |

## 최신 핸드오프와의 관계

새 [디자인 핸드오프](../../design-handoff.md)가 라벨·단지 핀, 상세·검색 동작을
구체화했다. 이 문서의 기존 cluster·zoom·상세/검색 미정 기록은 9월 제안이며 새
핸드오프와 충돌한다. 다음 지도 구현 전 SDD 요구사항·수용 기준을 새 디자인과
API 계약에 맞춰 갱신한다. 모바일 지원 정책은 이번 갱신으로 반영했다.
