# 지도 탐색 요구사항

> 상태: 제안
> 현재 버전: v0.4
> 최종 변경: 2026-10-13
> 관련 Notion: [서비스 기획안](https://app.notion.com/p/9564038ee1da8376a998011ae64b138c?pvs=204)

## 사용자 흐름

1. 사용자는 지도에서 시군구와 생활권 권역의 위치와 범위를 확인한다.
2. 사용자가 지도를 확대하면 권역을 더 자세히 탐색한다.
3. 충분히 확대한 지도에서 사용자는 단지 군집 또는 개별 단지를 확인한다.
4. 사용자가 cluster를 선택하면 지도는 해당 위치를 중심으로 zoom을 2단계 높여
   이동한다. 이때 단지 목록이나 상세 패널은 열지 않는다.

권역과 개별 단지를 선택한 뒤 보여 줄 상세 정보와 진입 방식은 아직 확정하지
않았으며 [제품 결정](decisions.md)에서 관리한다.

## 플랫폼 지원과 진입 경험

- 1280×720 CSS px 이상에서 최신 안정 버전의 Chrome, Edge, Safari를 정식
  지원하고 품질을 보증한다.
- 모바일 웹도 정식 지원·QA 범위에 포함한다. 작은 화면과 터치 입력에 맞춘
  지도 조작과 화면 배치를 검증한다.
- 모바일 최소 viewport·브라우저/OS 범위와 좁은 데스크톱 배치는 추가 확정한다.
  모바일 접속만을 이유로 데스크톱 권장 안내를 표시하지 않는다.

## 확대 수준별 탐색

| 확대 수준 | 사용자에게 보이는 탐색 결과 |
| --- | --- |
| zoom 0~11 | 시군구와 권역 경계를 확인할 수 있으며 단지 결과는 표시하지 않음 |
| zoom 12~13 | 여러 단지를 묶은 cluster를 표시 |
| zoom 14~21 | 개별 단지를 표시 |

이 구분은 현재 임시 기준이다. 실제 데이터 수, 브라우저 성능과 확정 디자인을
검증한 뒤 바뀔 수 있으며, 변경 기준은 [제품 결정](decisions.md)에 기록한다.

## 결과와 오류 상태

- 현재 지도 범위에 단지가 없으면 경계 탐색을 유지하고 결과 없음 안내를
  표시한다.
- 단지 결과가 제한되면 경계 탐색을 유지한다. 확대 안내, cluster 재전환, 목록
  제공 중 어떤 다음 행동을 제공할지는 아직 확정하지 않았다.
- 지도 SDK loader의 네트워크 실패에는 지도 자체를 불러올 수 없다는 안내와
  재시도 행동을 제공한다.
- 지도 API 조회 네트워크 실패에는 현재 범위의 지도 데이터를 불러올 수 없다는
  안내와 재시도 행동을 제공한다.
- 지도 SDK 인증 실패에는 재시도 대신 서비스 운영 설정 확인 안내를 표시한다.

## 제외 범위

시세·민심 급지 전환, 지역·평형·연차 필터, 통합 검색, 지도 공유 URL은 Notion
초안에 있으나 현재 Git 제품 기준에서는 확정하지 않았다. 상세한 미결 목록과
다음 검토 조건은 [제품 결정](decisions.md)을 따른다.

## 관련 기술 문서

지도 API 계약, 요청·캐시·취소 처리, SDK 수명주기, 오류 구현, 성능 기준은
[지도 API·운영 기준 설계](../../../superpowers/specs/2026-09-19-map-api-and-runtime-design.md)와
[프론트엔드 기반 기술 구조](../../../architecture/frontend-foundation.md)에서 관리한다.

## 최신 핸드오프와의 관계

새 [디자인 핸드오프](../../design-handoff.md)가 라벨·단지 핀, 상세·검색 동작을
구체화했다. 이 문서의 기존 cluster·zoom·상세/검색 미정 기록은 9월 제안이며 새
핸드오프와 충돌한다. 다음 지도 구현 전 SDD 요구사항·수용 기준을 새 디자인과
API 계약에 맞춰 갱신한다. 모바일 지원 정책은 이번 갱신으로 반영했다.
