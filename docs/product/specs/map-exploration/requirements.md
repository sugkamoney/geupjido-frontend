# 지도 탐색 요구사항

> 상태: 실제 NAVER 지도 연결·자동 검증 완료 · 모바일 실기기·실제 데이터 대기
> 현재 버전: v0.11
> 최종 변경: 2026-10-27

## 기준과 사용자 흐름

생김새는 Figma Screens와 Components, 동작·시간·문구는 Downloads 00/02/03/04/08/09 MD를 따른다. 지도 예시의 정수 줌은 화면 이름이며 전환 기준이 아니다.

1. 처음 전체 보기에서 구 라벨을 탐색한다. 구 라벨 선택은 여백 48로 구를 맞추고 줌을 12.55~13.5로 제한한다.
2. 권역 라벨 선택은 상세를 열고 가려지지 않은 지도 영역 가운데로 이동한다. 줌을 유지하되 12.5 미만이면 12.5로 올린다.
3. 지도 단지 핀 선택은 카메라를 유지하고 소속 권역 상세와 목록 행을 선택한다. 선택 행은 목록 가운데로 스크롤한다.
4. 목록/검색의 단지 선택은 해당 단지를 가려지지 않은 영역 가운데에 두고 줌 max(현재, 15)로 이동한다. 모바일 목록 선택은 시트를 접는다.
5. 상세 닫기와 ‘구’ 전환은 권역·단지 선택을 모두 해제한다. 닫기는 선택을 시작한 요소 또는 남아 있는 지도 메뉴로 focus를 복귀한다.

## 확대와 표시

- 최소 9.5, 최대 17. 확대/축소 조작은 1단계씩이다.
- 12.5 미만은 구 라벨, 12.5 이상은 권역 라벨이다. 선택 권역 라벨은 더 낮은 줌에서도 유지한다.
- 14.5 이상은 viewport 안 모든 단지 핀, 미만은 선택 핀 하나만 유지한다.
- 기본 구 경계·구 면·전체 권역 면은 표시하지 않는다. 선택 권역 면 하나만 표시한다. 12.5 미만은 면을 숨긴다.
- 선택 면은 테두리 2.5, 채움 30%. 13.5~14.5에서 10%까지 연속 감소한다. 실제 권역 면에는 한강이 포함되지 않아야 한다.
- 라벨 충돌 시 선택 라벨 → 넓은 권역 순으로 남기고 나머지는 선택 가능한 중심 점으로 표시한다. 선택 권역과 충돌하는 구 라벨도 점으로 표시한다.
- 단지 이름은 세대 수 큰 순으로 배치하고 권역 라벨·핀·다른 이름과 겹치면 숨긴다. 선택 단지 이름은 유지한다. 일반 이름 폭은 150 이하, hover는 전체 이름이다. 선택 이름은 전체 폭을 유지하며 이 영역과 겹치는 다른 이름은 숨긴다.
- ‘구’는 서울·경기 전체 보기, ‘권역’은 max(현재, 12.9) 및 선택 권역/기본 위치로 이동한다. 상세가 있으면 전환 UI는 항상 ‘권역’이다.

## 클릭 확대와 이동

구/권역 선택, 목록 단지 선택, 구/권역 전환과 지도 조작 버튼의 카메라 이동은 현재 위치·배율에서 목표까지 점진적으로 전환한다. 연속 조작은 새 목표를 따르고, 직접 지도 조작이나 지도 핀 선택·상세 닫기는 진행 중인 이동을 중단한다. OS/브라우저의 이동 효과 줄이기 설정이 켜져 있으면 목표 상태를 즉시 적용한다. 목표 줌·선택/해제·지도 핀의 카메라 유지 규칙은 동일하다.

## 마우스·키보드·모바일

PC 라벨/점 hover 100ms 후 위 8에 카드 표시, 공간 부족 시 아래, 지도 가장자리 8 안쪽에 둔다. 카드가 열린 채 다른 라벨로 이동하면 즉시 교체한다. 이탈 120ms 후 닫고 누르거나 지도 이동 시 즉시 닫는다. 모바일에는 hover 카드를 표시하지 않는다. 터치와 키보드로도 라벨/핀을 직접 선택한다.

모바일은 아래 시트·목록과 지도 제스처가 독립적이다. 접힌 시트에는 선택 단지 한 줄을 요약 스크롤과 분리해 계속 보이고 다시 누르면 단지로 확대한다. 키보드로 목록에서 선택해 시트가 접히면 이 행으로 focus를 이동한다. 짧은 모바일 화면의 펼친 시트는 목록 제목을 유지하고 요약과 목록을 각각 스크롤해 마지막 단지까지 접근할 수 있다. 이 배치는 지원 최소 화면 크기를 확정하지 않는다. 확대/축소 버튼은 모바일에서 숨기고 핀치·두 번 탭 및 전체 보기로 조작한다. 기존 768 breakpoint·시트 높이·좁은 데스크톱 배치는 검토 가정이며 최소 지원 정책이 아니다.

## 실제 지도 바탕과 상태

- 지도 바탕은 NAVER 지도(GL)다. 라벨·핀·선택 면·hover 카드는 지도 위에 직접 그린 overlay이며 드래그·관성·휠·핀치·두 번 탭 확대는 지도가 처리한다. 지도를 움직이다 놓은 입력은 라벨·핀 선택으로 이어지지 않는다.
- 지도 준비 전에는 로딩 표시를 보이고 라벨·핀은 그리지 않는다. 그 사이 검색·목록·권역 선택은 즉시 상세에 반영되며 지도 이동은 가장 최근 선택 한 곳으로 준비 직후 이동한다. 준비 전 확대/축소 버튼과 화살표·+/- 키는 동작하지 않는다.
- 지도를 불러오지 못하면 지도 영역에 안내와 `다시 시도` 버튼을 보이고 라벨·핀은 그리지 않는다. 가상 grid로 대체하지 않는다.
  - 인증 실패: `지도 인증에 실패했습니다. 등록된 주소에서 접속했는지 확인해 주세요.`
  - 네트워크 오류·시간 초과: `지도를 불러오지 못했습니다. 네트워크를 확인하고 다시 시도해 주세요.`
  - 설정 누락: `지도 설정이 없습니다.`
  - `다시 시도`는 인증 실패·설정 누락에서 페이지를 다시 불러온다. 이때 선택·검색·시트 상태는 사라진다. 네트워크 오류·시간 초과는 페이지를 유지한 채 지도만 다시 불러온다. 구조는 [지도 탐색 구조](../../../architecture/map-exploration.md#알려진-한계와-디자인-리뷰-항목)를 따른다.
- 검토용 데이터는 서울 25개 구와 경기·인천 10개 묶음 구 라벨(35개), 권역 163곳을 가진다. 전체 보기는 서울과 경기·인천 권역을 모두 포함한다. 권역 단계로 전환할 때 선택 권역이 없으면 전체 보기 중심으로 이동하므로 서울 남동부가 바로 보이지 않을 수 있다(알려진 동작, 제품 검토 필요).
- 검토용 좌표 고지는 계속 보인다. 위치는 실제 서울 지도 기준의 대략적인 검토용 값이며 실제 경계·지적·시세 자료가 아니다. 한강·행정동 등 NAVER 기본 지도의 POI·라벨은 숨기지 않아 검토용 라벨·핀과 겹칠 수 있다([제품 결정](decisions.md)).
- 줌 수치는 NAVER zoom 그대로 쓴다. 실제 축척에서 권역이 작게 보이는 것(구 선택 zoom 13에서 압구정 면 약 150px)은 디자인 기준의 결과이며 좌표를 키워 보정하지 않는다. 화면 밀도는 디자인 리뷰 대상이다.
- 모바일은 데스크톱 브라우저의 모바일 에뮬레이션과 자동 테스트까지 확인했다. 실기기 지도 제스처는 미검증이다([플랫폼 지원](../../platform-support.md)).

## 상세와 데이터가 없는 상태

권역 이름·위치·급지 카드·단계·비교 버튼·시세순 단지 목록을 구성한다. 표본/단계/색 경계를 프론트에서 계산하지 않는다. 가격은 만원÷10,000의 소수 둘째 자리 억, 면적은 반올림 ㎡, 세대 수는 천 단위 쉼표로 표시한다. 선택 상세에서 제공된 최신 권역·단지 표시값을 반영한다. 제공되지 않은 값은 미연결 상태로 안내한다. 비교 버튼은 후속 월드컵 연결까지 비활성이다.

기술·API·좌표계·취소·오류 구현과 검증 결과는 [아키텍처](../../../architecture/map-exploration.md)에서 관리한다.
