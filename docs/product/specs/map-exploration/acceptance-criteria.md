# 지도 탐색 수용 기준

> 상태: 제안
> 현재 버전: v0.3
> 최종 변경: 2026-09-22
> 관련 Notion: [서비스 기획안](https://app.notion.com/p/9564038ee1da8376a998011ae64b138c?pvs=204)

## 수용 기준

| ID | 사전 조건 | 사용자 행동 | 관찰 가능한 결과 |
| --- | --- | --- | --- |
| AC-001 | 1280×720 CSS px 이상의 지원 브라우저에서 지도 탐색을 열 수 있음 | 사용자가 지도를 이동하고 확대함 | 시군구와 권역 경계를 계속 확인할 수 있음 |
| AC-002 | 지도 탐색 화면이 열려 있음 | 사용자가 zoom 11, 12, 13, 14, 21을 차례로 확인함 | zoom 11에서는 단지 결과가 없고, zoom 12·13에서는 cluster가, zoom 14·21에서는 개별 단지가 표시됨 |
| AC-003 | zoom 12~13에서 cluster가 보임 | 사용자가 cluster를 선택함 | 지도 중심이 해당 위치로 이동하고 zoom이 2단계 높아짐. 단지 목록이나 상세 패널은 열리지 않음 |
| AC-004 | 폭이 1280 CSS px 미만이거나 높이가 720 CSS px 미만인 viewport, 또는 모바일 브라우저로 접속함 | 사용자가 지도 탐색 화면을 열음 | 접근은 가능하며 “데스크톱 화면에서의 사용을 권장합니다” 안내가 보임. 이 환경의 레이아웃과 지도 조작 품질은 보장하지 않음 |
| AC-005 | 폭과 높이가 각각 1280×720 CSS px 이상인 데스크톱 지원 브라우저로 접속함 | 사용자가 지도 탐색 화면을 열음 | 데스크톱 권장 안내 없이 지원 화면이 보임 |
| AC-006 | 현재 지도 범위에 단지가 없음 | 사용자가 해당 범위를 탐색함 | 권역 경계 탐색은 유지되고 결과 없음 안내가 보임 |
| AC-007 | 개별 단지 결과가 제한됨 | 사용자가 해당 범위를 탐색함 | 권역 경계 탐색은 유지되고 결과 제한 상태가 안내됨. 다음 행동은 [제품 결정](decisions.md)이 확정한 정책을 따름 |
| AC-008 | 지도 SDK loader의 네트워크 로딩이 실패함 | 사용자가 오류 안내를 확인하고 재시도를 선택함 | 지도 자체를 불러올 수 없다는 SDK 네트워크 오류 안내와 재시도 행동이 보이며, 재시도에 성공하면 지도 탐색으로 복귀함 |
| AC-009 | 지도 API 조회가 네트워크 오류로 실패함 | 사용자가 오류 안내를 확인하고 재시도를 선택함 | 현재 범위의 지도 데이터를 불러올 수 없다는 API 조회 네트워크 오류 안내와 재시도 행동이 보이며, 재시도에 성공하면 현재 지도 탐색 결과를 다시 조회함 |
| AC-010 | 지도 SDK 인증이 실패함 | 사용자가 오류 안내를 확인함 | 재시도 버튼 대신 서비스 운영 설정 확인 안내가 보임 |

권역·개별 단지의 상세 정보와 상세 화면 진입 방식은 미결 제품 정책이므로 이
문서의 완료 조건에 포함하지 않는다.
