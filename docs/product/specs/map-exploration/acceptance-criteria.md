AC-019~027의 실제 SDK 확인 결과: AC-019·020·021·022는 데스크톱 실제 GPU Chrome에서 수동 확인했다. AC-023·024·026은 수동 미검증이며 adapter 단위·RTL 테스트로만 확인했다. AC-025는 E2E의 NAVER 오류 구성과 RTL로 확인했다. AC-027은 실제 SDK에서 미검증이고 모바일 에뮬레이션 headless 점검과 fixture E2E까지다. 상세와 이유는 [기술 문서](../../../architecture/map-exploration.md)에 있다.

현재 fixture 검증과 실제 SDK/API smoke 결과는 [기술 검증 표](../../../architecture/map-exploration.md)에서 구분한다. 실기기 및 실제 데이터 시나리오 통과 전 전체 제품 연결 완료로 표시하지 않는다.
