## 미확정 사업 정책

인증·익명 ID, 중복 투표, 넘김 집계, 서버 대진 생성(6:4·우선순위·반복 제한 포함), 비율 공개 임계값과 사람/표 단위, 단계 전환 기준, 급지 갱신 주기, 타임라인 숨김 임계값은 09-open 미확정이다. 검토 source의 순서·비율·표시 여부는 UI 시나리오이며 실제 규칙으로 채택하지 않는다. 실제 선택이 지도 급지에 반영된다고 보장하지 않는다. 다음 검토는 제품/API 계약 확정 전이다.
