# 월드컵 결정

> 상태: 배포 계약 반영, 실기기·운영 배포 검증 남음 · 버전: 1.1 · 최종 갱신: 2026-11-20

## 확정 결정

| 결정 | 근거 | 다음 검토 |
|---|---|---|
| 일반 고정 10판(권역 안4·권역 간6), 한국 날짜별 최대6게임·60판, 10판마다 다음 게임 연결 | 배포 계약·Figma UC-W4 | 서버 게임 정책 변경 시 |
| 권역 비교는 그 권역만10판, 활성 단지5곳 필요, 일반 한도에서 제외·날짜 넘어도 이어하기 | 배포 계약·권역 상세 비교 | 후보/시작 정책 변경 시 |
| 익명 쿠키 이어하기, 확정 판 변경 불가, 넘김은 진행에 포함·표에는 제외 | 배포 계약 | 식별·진행 계약 변경 시 |
| 비율은 서버가 제공한 선택 비율만 표시, 급지는3시간 발행 | 배포 계약·Figma UC-W2 | 집계 계약 변경 시 |
| 전체 최근 선택5건 미만이면 타임라인 숨김, 권역 필터 빈 결과와 구분 | 백엔드 타임라인 문서·기존 디자인 | 공개 노출 정책 변경 시 |
| My Picks는 현재 페이지에서 성공 확인된 선택만 누적, 새로고침 초기화 | 전체 개인 이력 API 없음·인계 범위 | 개인 이력 API 도입 시 |
| 오늘 진행은 일반 선택+넘김, 30/60판 목표 표시 | 배포 progress 계약 | 개인 리포트 제공 시 |
| 대표 거래·계약일 표시, 없는 역/소개 생략 | 백엔드 카드 계약 | 추가 카드 데이터 도입 시 |
| 첫 설명은 브라우저 저장 영역에서 한 번, 익명 식별과 분리 | 기존 요구사항 | 배포 origin 변경 시 |
| 모바일은 전체화면 대진·권역 비교 지원, 타임라인 패널 미제공 | 기존 모바일 지원 범위 | 모바일 UX 개편 시 |

데스크톱 배치는 화면 높이의 고정 임계값으로 보정하지 않고 My Picks의 실제 높이를 전체 묶음에 포함한다. 타임라인 이동보다 이후의 지도 탐색을 우선한다. 기술 근거와 검증은 [기술 문서](../../../architecture/worldcup.md#pr-11-리뷰-회귀-보완)를 따른다.

## 남은 검토

| 항목 | 현재 처리 | 다음 검토 |
|---|---|---|
| 개인30/60판 리포트·과거 전체 개인 선택 | 이번 범위에서 제공하지 않음 | 별도 제품/API 착수 시 |
| 물리 iOS/Android·IME·VoiceOver·주소창/회전 | 자동 브라우저 모사 결과와 구분 | 실기기 QA 가능 시 |
| 배포 origin·쿠키의 실제 저장·운영 브라우저 | 상대 `/api` 배포 계약 사용, 격리 HTTPS 자동 검사 | HTTPS 배포 smoke 시 |

게임 상태 선택의 근거는 [ADR-009](../../../history/ADR-009-worldcup-server-game-state.md), 기술 선택·요청 경합·배포 제약은 [기술 구조](../../../architecture/worldcup.md)를 따른다. 과거 검토 문서의 “API 없음·집계 정책 미정”은 현재 정책이 아니다.
