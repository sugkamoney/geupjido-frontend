# 월드컵 요구사항

> 상태: 검토 UI 구현·검증 완료, 실제 연동·사업 정책 미확정 · 버전: 0.1 · 최종 갱신: 2026-10-15

## 진입과 설명

데스크톱 메뉴는 타임라인을 열고 [월드컵 시작]은 전체 대진을 연다. 권역 상세 [이 권역 단지 비교하기]는 그 권역의 단지끼리만 비교한다. 비교 가능한 쌍이 없으면 안내한다. 모바일 탭은 전체 월드컵에 직접 진입하며 타임라인은 제공하지 않는다.

W-01은 같은 origin·브라우저 저장 영역에서 최초 표시 시 한 번만 보인다. 상세 진입도 동일하다. 제목은 `두 곳 중에` / `더 살고 싶은 곳을 고르세요`, 안내는 `고른 결과는 모여 민심급지에 반영됩니다`, 버튼은 `시작하기`다. 저장 차단 시 현재 페이지에서만 한 번을 보장하며, 데이터 삭제·사생활 모드·다른 기기는 새 브라우저 저장 영역으로 본다. 사용자 식별을 뜻하지 않는다.

## 대진과 결과

데스크톱 창은 600×468, 화면 중앙 기준이며 내 선택 판(600×120)은 창 위 12px에 별도로 놓인다. 모바일은 전체 화면, 내 선택 판을 상단 내부에 놓고 두 카드를 위아래로 배치한다. 짧은 화면은 스크롤과 고정 닫기를 제공하며 가까운 역 줄은 숨길 수 있다.

질문은 `어디 살고 싶으세요?`, 안내는 `고른 기록은 민심급지를 산정할 때 함께 쓰여요.`다. 카드 전체 또는 [선택]으로 한 번만 제출한다. 선택 전 급지 색·값을 숨기고 성공한 선택/넘김 후 표시한다. 고른 카드만 왕관과 `선택했어요`, 상대는 55%, 넘김 버튼은 50%로 표시한다. 넘김 후 두 카드는 흐리지 않는다. 역은 실제 데이터 연결 전 `가까운 역 —`다. 면적은 MD 카드 표기 `m²`를 사용한다.

소개 한 줄은 권역 단지 1곳이면 `지은 지 {n}년`, 여러 곳이면 혼자 세대수 최다 → 혼자 가장 최근 준공 → 혼자 거래가 최고 → 혼자 가장 오래됨 → `{권역} 단지 {N}곳 중 거래가 {r}번째` 순서다. 누락 데이터는 순위·연식을 만들지 않고 `단지 정보를 준비하고 있어요`를 표시한다.

공개된 비율이 있으면 성공 뒤 1.1초, 비율 미공개/조회 실패 또는 reduced motion이면 0.6초 뒤 다음 판이다. 비율 공개 조건은 미확정이므로 제공된 표시 상태만 따른다. 넘김은 `잘 모르겠어요`이며 횟수에 포함하지 않는다. 실패 시 같은 판에서 재시도하고 선택 수·타임라인·진행을 바꾸지 않는다. 닫기는 즉시 가능하다.

## 내 선택과 타임라인

내 선택은 20칸을 채우고 이후에도 누적 수는 증가한다. `n/10` 진행·완성 화면은 없다. 0개는 `아직 담긴 선택이 없어요`, 이후 `{n}개의 선택이 담겼어요`. 작은 문구는 평소 `고를 때마다 한 칸씩 채워져요`(20개부터 `고른 곳은 계속 담겨요`), 선택 직후 `‘{이름}’을/를 담았어요`(조사 적용), 넘김 직후 `넘긴 판은 담기지 않아요`이며 2.4초 뒤 평소 문구로 돌아간다.

타임라인은 이름·시간과 두 결과 칸을 제공하고 비율은 표시하지 않는다. 각 칸은 해당 권역 상세를 연다. 전체/선택 권역 필터를 제공한다. 권역 변경은 스크롤 유지, 칩 변경은 맨 위다. 목록 표시 여부는 데이터 제공자가 결정하며 임의 숫자 임계값을 두지 않는다. 검토용 타인 행은 실제 활동으로 표시하지 않는다. 본인 성공 선택은 `나`로 추가한다.

검토용 누적 수·내 선택·타임라인은 페이지 메모리에만 두며 새로고침 시 초기화한다. 모달 닫기/재진입·권역 변경에는 누적을 유지한다. 실제 계정·서버 저장/동기화는 미확정이다.
