# 월드컵 요구사항

> 상태: 실제 API 연동·자동 검증 완료, 실기기·운영 검증 남음 · 버전: 1.1 · 최종 갱신: 2026-11-20

## 진입·설명·지원 화면

데스크톱 월드컵 메뉴는 타임라인 패널을 열고 [월드컵 시작]은 일반 월드컵을 연다. 모바일 메뉴는 일반 월드컵에 바로 진입한다. 권역 상세의 [이 권역 단지 비교하기]는 해당 권역 안 단지끼리 비교한다. 모바일 타임라인 패널은 제공하지 않는다.

첫 설명은 같은 origin의 브라우저 저장 영역에서 처음 표시할 때 한 번 기록한다. 저장이 차단되면 현재 페이지에서만 중복을 막는다. 데이터 삭제·사생활 모드·다른 기기는 새 저장 영역으로 본다. 첫 설명 기록은 방문자 식별이나 투표 저장을 뜻하지 않는다.

데스크톱은 기존 600px 창과 위쪽 My Picks 판을 유지하고 My Picks의 실제 높이·창·하단 안내를 포함한 전체 묶음을 중앙에 배치한다. 전체 높이가 화면을 넘으면 상단부터 세로 스크롤로 모두 접근하며, 긴 이름·피드백·글자 확대에서도 위가 잘리지 않아야 한다. 모바일 768px 미만은 전체화면·위아래 카드·내부 상단 My Picks를 사용한다. 짧은 화면에서는 세로 스크롤과 고정 닫기를 제공한다. 320×460에서도 선택·넘김·닫기에 접근할 수 있어야 한다. 물리 기기 지원 검증 범위는 [기술 문서](../../../architecture/worldcup.md)에 기록한다.

## 대진·이어하기·한도

일반 게임은 고정 10판이며 같은 권역 안 4판·다른 권역 6판으로 구성한다. 같은 익명 브라우저는 한국 날짜의 최근 미완료 일반 게임을 이어간다. 한국 날짜가 바뀌면 전날 카드에 계속 제출하지 않고 오늘 게임을 불러온다. 일반 게임은 하루 최대 6게임·60판이다. 10판을 마치면 결과 화면으로 끊지 않고 다음 게임을 이어가며, 한도 도달 시 오늘 종료와 한국 시간 자정 이후 재참여를 안내한다.

권역 비교는 해당 권역의 활성 단지가 최소 5곳이어야 시작할 수 있다. 그 권역 단지끼리 10판을 제공하며 일반 하루 한도·진행 수에 포함하지 않는다. 날짜가 바뀌어도 권역별 미완료 게임을 이어간다. 시작 불가 시 서버가 제시한 인접 대체 권역을 고를 수 있다. 적합한 대안이 없거나 목록 조회가 실패하면 각각 빈 상태·재시도를 제공한다. 최종 시작 결과가 우선한다.

## 선택·피드백·오류

카드 전체나 [선택]은 한 번만 제출하고 처리 중에는 선택·넘김을 잠근다. 선택 전 급지 색·값과 비율을 숨긴다. 확정된 선택 뒤에는 왕관·선택 문구·양쪽 급지와 상대 카드 55% 흐림을 보여준다. 넘김은 두 카드를 흐리지 않는다. 닫기는 처리 중에도 가능하다.

서버가 공개한 선택 비율만 표시한다. 공개 비율은 1.1초, 비공개·복구된 결과 또는 reduced motion은 0.6초 뒤 다음 대진으로 진행한다. 퍼센트를 사람 수나 급지 점수로 해석하지 않는다. 급지·단지 순위는 3시간마다 발행되므로 선택 직후 지도 값이 바뀐다고 안내하지 않는다.

실패하면 성공·선택 수·다음 판을 만들지 않는다. 다른 요청과 충돌하면 최신 진행을 다시 불러오고 새 성공 선택으로 세지 않는다. 응답이 끊겨 결과를 모를 때는 재시도 시 저장 여부부터 확인하며, 이미 확정된 선택을 바꾸지 않는다. 닫기·권역 전환 뒤 옛 응답은 새 화면과 누적 수에 영향을 주지 않는다. 구체적인 요청·오류 처리는 [기술 구조](../../../architecture/worldcup.md)를 따른다.

## 카드 정보

단지명, 시·구·권역명, 현재 권역 급지, 사용승인 연도, 세대수, 대표 거래의 전용면적·가격·계약일을 표시한다. 가격은 `대표 거래`이며 전체 평형 중 최근 계약이라는 의미가 아니다. 실제 API에 없는 가까운 역·한 줄 소개를 만들지 않는다. 면적 단위는 기존 카드의 `m²`를 유지한다.

## 내 선택·오늘 진행

My Picks는 현재 페이지에서 성공이 확인된 선택만 누적한다. 넘김은 제외하고 20칸 이후에도 수를 늘리며 완료 화면은 없다. 닫기·재진입·권역 변경에는 유지하되 새로고침 시 초기화한다. 서버에 저장된 과거 전체 개인 선택을 복원했다고 표시하지 않으며, 보존 범위를 화면에 명시한다.

`아직 담긴 선택이 없어요` / `{n}개의 선택이 담겼어요`, 선택 뒤 조사에 맞는 `‘{이름}’을/를 담았어요`, 넘김 뒤 `넘긴 판은 담기지 않아요`를 표시한다. 선택 피드백은 2.4초 뒤 평소 문구로 돌아간다.

오늘 일반 월드컵은 서버의 한국 날짜·확정 판 수·60판 한도·다음 30/60판 목표까지 남은 판을 표시한다. 선택과 넘김을 모두 포함하며 권역 비교는 제외한다. My Picks와 같은 숫자로 합치지 않는다. 30/60판 표시는 개인 리포트 제공을 의미하지 않는다.

## 데스크톱 타임라인

서버의 최근 선택 최대 20건만 표시한다. 넘김과 유효표 집계는 이 목록과 구분한다. 전체 선택이 5건 미만이면 타임라인 영역을 숨긴다. 전체/선택 권역 필터를 제공하고, 전체가 5건 이상이어도 선택 권역 결과가 비면 그 권역의 빈 목록을 안내한다.

본인 표는 `나`, 타인 표는 서버 표시명을 사용하고 선택 시각은 상대 시간으로 표시한다. 익명 표시명은 고유 사용자 식별자가 아니다. 양쪽 단지의 권역을 누르면 실제 권역 상세를 불러온다. 응답을 기다리는 동안 검색·지도/목록 선택·상세 닫기·지도 이동 등 새 탐색이 발생하면 이전 타임라인 이동은 무효화한다. 같은 권역을 다시 선택해도 최신 탐색을 우선하며, 전체/권역 필터와 무관하게 적용한다. 카드에 없는 좌표·급지를 만들어 이동하거나 표시하지 않는다. 권역 변경에는 스크롤을 유지하고 필터 칩을 바꿀 때만 맨 위로 이동한다. 조회 오류에는 재시도를 제공하며 예시 활동을 추가하지 않는다.
