# 월드컵 SDD

> 상태: 실제 API 연동·자동 검증 완료, 실기기·운영 검증 남음 · 버전: 1.1 · 최종 갱신: 2026-11-20

## 목표와 대상

살고 싶은 단지·권역을 비교하려는 데스크톱·모바일 웹 사용자에게 실제 대진과 선택·넘김, 익명 이어하기, 오늘 진행 현황을 제공한다. 데스크톱에서는 최근 공개 선택 타임라인도 제공한다.

기본 지도(`/`, `/map-exploration`)는 서버 월드컵을 사용한다. `/worldcup?scenario=`와 `/map-exploration/fixtures`는 실제 투표·집계와 무관한 명시적 검토 경로다. 서버 오류를 예시 대진이나 가짜 활동으로 대체하지 않는다.

## 범위와 기준

일반 10판 게임과 연속 다음 세트, 권역 안 단지 비교, 시작 불가 권역의 인접 대안, 선택 비율, 오늘 일반 월드컵 진행, 최근 선택 20건을 연결한다. 첫 설명·My Picks·모달 접근성·모바일 전체화면을 유지한다.

시각·동작 기준은 [Figma 작업공간](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU?node-id=378-8361)이며, 04 전체를 최종 승인된 화면으로 간주하지 않는다. 10판 이후 이어가기는 UC-W4, 비율 피드백은 UC-W2를 따른다. 실제 저장·대진·일일 한도는 현재 배포 계약에 맞춘다.

개인 30·60판 내 선택 리포트, 공개 주간 리포트, 완성 화면, 전체 과거 개인 선택 복원, 지도 상태 카드·브랜드·모바일 레이아웃 개편은 범위 밖이다.
