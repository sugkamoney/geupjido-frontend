## 목표와 범위

지도에서 살고 싶은 권역·단지를 비교하는 데스크톱·모바일 웹 사용자에게 설명, 대진, 선택/넘김, 누적 내 선택과 데스크톱 타임라인을 제공한다. 실제 제품 API 연결 전 명시적인 검토용 예시로 제공한다.

Figma Screens W-01~06/W-08이 시각 기준이고 Downloads 00/06/07/08/09 MD가 동작·시간·문구 기준이다. 모바일 HTML은 참고다. 기존 디자인 시스템·화면 틀·지도·검색은 develop에 병합됐다. NAVER/실제 제품 API는 미연결이다.

20개 완성 화면·지도 보기·옛 온보딩·10판마다 결과는 범위 밖이다.
