# 월드컵 인수 기준

> 상태: 실제 API 연동·자동 검증 완료, 실기기·운영 검증 남음 · 버전: 1.0 · 최종 갱신: 2026-11-20

1. 데스크톱 패널 시작·모바일 메뉴·권역 상세에서 올바른 흐름으로 진입한다. 첫 설명은 한 번이고 저장 차단 시 페이지 안 중복을 막는다.
2. 처음 방문하면 새 게임을 시작하고 동일 익명 브라우저로 재진입·새로고침하면 저장된 다음 판을 이어간다. 일반·권역 진행은 서로 섞이지 않는다.
3. 선택·넘김 처리 중 중복 입력을 막고 서버 확인 뒤에만 피드백·진행을 반영한다. 공개 비율 1.1초, 비공개/reduced motion 0.6초, 별도 피드백 2.4초를 유지한다.
4. 충돌은 최신 진행으로 복귀하며 새 본인 선택으로 세지 않는다. 응답이 유실된 선택을 재시도하면 저장 여부를 확인하고 불필요한 중복 저장 요청을 하지 않는다.
5. 닫기·권역 전환·unmount 뒤 늦은 응답·타이머는 새 화면이나 My Picks를 바꾸지 않는다. 처리 중에도 닫을 수 있고 원래 버튼으로 focus가 돌아온다.
6. 일반 10판 이후 다음 게임으로 이어지고 하루 한도에 도달하면 종료·재참여 시점을 안내한다. 한국 자정에 조회 중이거나 카드가 열린 경우 오늘 게임을 다시 조회한다.
7. 권역 비교는 그 권역만 사용한다. 시작 불가 시 서버 대안 선택·대안 없음·조회 오류·재시도를 구분한다. 날짜 변경 후에도 권역 이어하기는 유지된다.
8. 카드에 대표 거래 가격·면적·계약일을 표시하며 가까운 역·소개·누락 숫자를 추정하지 않는다. 성공 전 급지는 숨기고 성공 뒤 공개한다.
9. My Picks는 페이지에서 확인된 선택만 세며 넘김은 제외한다. 오늘 일반 진행에는 넘김을 포함하고 권역 비교는 제외한다. 새로고침 뒤 My Picks 초기화와 서버 진행 유지가 함께 보인다.
10. 전체 선택 5건 미만이면 데스크톱 타임라인을 숨긴다. 전체/권역 필터·권역 빈 목록·조회 오류·양쪽 권역 상세 연결·본인 표시·스크롤 규칙을 확인한다. 예시 fallback은 없다.
11. 의미 있는 dialog 이름·focus 진입/순환/복귀·배경 inert·스크롤 잠금·Escape/IME·visible focus·touch를 유지한다. 320×460에서도 가로 overflow 없이 닫기·넘김에 접근한다.
12. desktop Chromium·mobile Chromium/WebKit과 지도·검색·시트 전체 회귀를 확인한다. 실제 기기·배포 API·격리 모의 서버 결과를 구분하고, 미병합 별도 스크롤 수정과 월드컵 변경의 실패를 구분한다.

실행 명령·기대/실제·미검증 사유는 [검증 기록](../../../architecture/worldcup.md)에 기록한다.
