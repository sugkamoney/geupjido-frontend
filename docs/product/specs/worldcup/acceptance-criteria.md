# 월드컵 인수 기준

> 상태: 검토 UI 구현·검증 완료, 실제 연동·사업 정책 미확정 · 버전: 0.1 · 최종 갱신: 2026-10-15

1. 데스크톱 타임라인 시작/모바일 직접 진입/상세 권역 비교에서 올바른 모달이 열린다. 첫 설명은 브라우저 저장 영역에서 한 번이며 차단 시 현재 페이지에서 반복하지 않는다.
2. 선택 전 급지·비율 숨김, 성공 뒤 왕관·상대 흐림·급지 공개, 넘김 뒤 양쪽 급지 공개를 확인한다. 전체 카드/내부 버튼/빠른 키보드 입력으로 중복 제출하지 않는다.
3. pending 중 입력을 막고 실패하면 횟수·진행을 유지하며 재시도할 수 있다. 닫기/재열기·권역 변경 후 옛 응답과 타이머는 새 화면·누적에 영향을 주지 않는다.
4. 비율 유무·실패·reduced motion의 1.1/0.6초와 피드백 2.4초를 확인한다. 21번째 선택도 종료 없이 이어지고 넘김은 세지 않는다.
5. 소개 우선순위·동률·누락 자료·한 단지 분기를 확인한다. 역은 —이며 숫자를 추정하지 않는다.
6. 의미 있는 dialog 이름, 진입 focus·Tab 순환·복귀, 배경 inert·스크롤 잠금, Escape/IME·visible focus·touch를 확인한다.
7. 타임라인 두 칸 모두 권역 상세로 이어지고 선택 쪽이 좌/우일 수 있다. 권역 필터 변경은 scroll 유지, 칩 변경은 초기화하며 sparse 표시는 source 지시를 따른다.
8. desktop Chromium과 모바일 Chromium/WebKit, 좁고 짧은 화면·긴 문구를 검증하고 기존 지도/검색/시트 회귀를 유지한다. 실기기 IME/VoiceOver·실제 SDK/API 검증은 별도 한계로 명시한다.

실제 기대/결과는 [기술 검증 기록](../../../architecture/worldcup.md)에 기록한다.
