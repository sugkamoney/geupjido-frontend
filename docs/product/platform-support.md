# 플랫폼 지원 범위

> 상태: **확정** · 갱신: 2026-10-27

## 초기 지원 범위

급지도의 제품은 **데스크톱과 모바일 웹 브라우저**를 지원한다.

- 데스크톱 화면 크기와 마우스·키보드 입력을 기준으로 UX를 설계하고 검증한다.
- 모바일 웹도 제품 및 품질 보증 범위에 포함한다. 작은 화면과 터치 입력에 맞춰
  지도, 검색, 권역 상세, 월드컵 흐름을 구현하고 검증한다.
- 데스크톱은 기존 Chrome·Edge·Safari 최신 안정 버전과 1280×720 CSS px 이상을
  검증 기준으로 유지한다. 좁은 데스크톱 배치는 새 디자인과 조율한다.
- 모바일의 최소 viewport, 지원 브라우저·OS 버전, 세부 배치는 구현 전에 확정한다.
  참고 시안의 390×844를 최소 지원 크기로 자동 확정하지 않는다.

## 모바일 디자인과 검증

제공된 모바일 HTML과 `08-mobile.md`는 참고 자료다. 모바일을 지원하기로 한
제품 결정이 시안 전체를 확정하는 것은 아니다. 하단 탭, 아래 시트, 전체 화면
검색·월드컵 방향을 검토하고 미정 동작과 배치를 확인한다.

모바일은 화면 축소뿐 아니라 터치 지도 조작, 시트·목록 스크롤, 가상 키보드가
열린 검색, 화면 높이 변화, 모달과 포커스를 검증한다. PC hover 카드는 모바일에
그대로 적용하지 않는다. 결정 이력은 [ADR-004](../history/ADR-004-mobile-web-support.md),
자료 기준은 [디자인 핸드오프](design-handoff.md)를 따른다.

## 실제 지도의 모바일 검증 범위

NAVER 지도 연결(2026-10-27) 시점의 모바일 확인은 데스크톱 브라우저의 모바일 에뮬레이션과
자동 테스트까지다. 실제 SDK 위의 모바일 터치 드래그·핀치·두 번 탭 확대는 에뮬레이션
headless 점검에서 라벨 위 입력이 지도로 전달되는 것만 보았고, 실기기(iOS/Android)는
미검증이다. 실기기 확인에는 접속 origin을 NAVER 콘솔에 등록해야 한다. 작은 화면의
지도 밀도와 최소 viewport는 계속 미결이다. 결정은 [ADR-007](../history/ADR-007-naver-gl-map-and-react-overlay.md)을 따른다.
