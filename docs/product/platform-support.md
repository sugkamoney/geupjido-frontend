# 플랫폼 지원 범위

> 상태: **확정** · 날짜: 2026-09-19

## 초기 지원 범위

급지도의 초기 제품은 **데스크톱 웹 브라우저**를 지원한다.

- 데스크톱 화면 크기와 마우스·키보드 입력을 기준으로 UX를 설계하고 검증한다.
- 모바일 웹은 초기 출시의 지원 및 품질 보증 범위에 포함하지 않는다.
- 모바일 브라우저 접속을 의도적으로 차단하지는 않지만, 레이아웃과 지도
  조작이 정상 동작한다고 보장하지 않는다.

## 모바일 웹 재검토 조건

다음 중 하나가 확인되면 모바일 웹 지원을 별도 제품 작업으로 검토한다.

- 실제 사용자 유입에서 모바일 비중이 의미 있게 증가한다.
- 모바일 사용 시나리오와 핵심 화면이 정의된다.
- 데스크톱 기능을 모바일에 맞게 재구성할 UX와 테스트 여력이 확보된다.

모바일 지원을 시작할 때는 단순 화면 축소가 아니라 지도 위 패널, 필터,
권역·단지 상세 정보를 작은 화면과 터치 입력에 맞게 다시 설계한다.
