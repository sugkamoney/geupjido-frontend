# 디자인 핸드오프 기준

> 수신·검토: 2026-10-13 · 데스크톱·모바일 웹 지원, 기획 미정값은 가정

## 자료 우선순위

- 크기·색·글자·간격·시각 상태는 [Figma](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU)를
  기준으로 한다. HTML/MD와 시각적으로 다르면 Figma가 우선한다.
- 동작·조건·시간·문구는 제공된 MD `00-README.md`~`09-open.md`를 따른다.
  동작 설명과 화면 상태가 충돌하는 경우 충돌을 기록해 확인한다.
- Desktop UI + 브랜드 시트 HTML은 확정된 참고 시안이다. 과거 옵션·데모 문구도
  포함하므로 소스 전체를 현재 제품 명세로 취급하지 않는다.
- 모바일·월드컵 선택판 HTML은 참고용이다. 특히 선택판 HTML의 20개 완성 화면·
  지도 보기 흐름은 MD에서 이번 범위 밖이다.
- `09-open.md`와 별도 `기획-논의-필수.md`의 가정값은 확정 정책이 아니다.

Figma 페이지: [Foundations](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU?node-id=81-3),
[Components](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU?node-id=82-4),
[Screens](https://www.figma.com/design/VB4hekcKLXEAyuFPu4zhVU?node-id=82-5).
Components 페이지는 인스턴스 모음이고 원본은 작업공간에 있다. 작업공간의 화면
전체를 확정 화면으로 취급하지 않는다.

원본은 사용자 Downloads의 `민심급지도-md-전체` 폴더와 HTML 3개다. 원본 파일은
저장소에 복사하지 않았으므로 다음 개발 환경에서도 접근 가능 여부를 확인한다.

## 현재 핸드오프의 제품 동작

- 1920×1080 기준: 레일 64, 타임라인 패널 390, 권역 상세 360, 검색 340px.
  패널 상태에 따라 검색을 옮기고 선택 권역을 가려지지 않은 지도 영역에 맞춘다.
- 지도는 NAVER 기반이다. zoom 12.5부터 권역 라벨, 14.5부터 전체 단지 핀,
  최소 9.5·최대 17. 기본 면은 숨기고 선택 권역 면만 표시한다.
- 권역 상세는 급지·단계와 단지 시세순 목록을 표시한다. 목록만 스크롤하며
  지도·목록·검색의 단지 선택 상태를 연결한다.
- 검색은 권역·구·단지를 묶어 표시하고 방향키·Enter·Esc로 조작한다.
- 데스크톱 월드컵 메뉴는 타임라인 패널을 연다. 패널 시작 버튼이나 상세의
  비교 버튼으로 월드컵 모달을 열며 브라우저 첫 진입 설명을 한 번 표시한다.
- 선택 전 급지는 숨긴다. 선택/넘김 후 결과를 표시하고 보통 1.1초 뒤 진행한다.
  비율 미공개/조회 실패 또는 reduced motion이면 0.6초를 사용한다. 공개 기준은
  기획 미정이며 현재 시안은 10명이다.
- 내 선택 판은 넘김을 제외한 선택 수를 누적한다. 20칸이 차도 숫자는 계속
  증가하며 별도의 완성 화면이나 지도 보기로 전환하지 않는다.
- 타임라인은 선택 결과를 보여 주고 권역 상세로 연결한다. 대진 비율은 표시하지 않는다.

## 기획·디자인 확정이 필요한 항목

급지 범위(기획 1.0~5.0 / BE schema 1.0~5.9), 색 경계, 단계 전환(가정 40/80회),
로그인/익명 식별·중복 투표·넘김 산정, 대진 생성(가정 권역 6+단지 4판), 비율 공개
기준과 사람/표의 단위, 급지 갱신 주기, 타임라인 숨김 기준, 서비스 이름을 확인한다.
랭킹·리포트는 화면이 없으므로 메뉴 노출 정책도 필요하다. 면적 단위 `m²`/`㎡`도
통일해야 한다.

공통 UI 구현·코드 리뷰에서 Figma 급지 1·4·5의 흰 글자와 Primary 버튼 흰 글자의
명도 대비가 일반 텍스트 4.5:1에 못 미침을 확인했다. 제품 화면 적용 전에
접근 가능한 색상 조합을 디자이너와 검토한다. 현재 원본 색을 임의 변경하지 않았다.
원본 속성·구현 확장과 검증 제약은 [디자인 시스템](../architecture/design-system.md)에 기록한다.

## 반응형 범위

모바일 HTML과 `08-mobile.md`는 하단 탭·아래 시트·전체 화면 검색/월드컵 방향을
설명하지만 참고용이다. 2026-10-13 사용자가 모바일 웹 지원을 확정했으므로
모바일도 구현·QA 범위에 포함한다. 지원 결정과 시안 확정은 구분하며, 세부
배치·지원 브라우저·최소 viewport는 추가로 확정한다.
[플랫폼 지원 범위](platform-support.md)를 따른다.

기존 최소 QA 기준은 1280×720이지만 이번 디자인은 1920보다 좁은 화면에서 줄일
요소를 범위 밖으로 기록했다. 고정 패널·검색 폭을 모두 유지하면 지도 공간이
부족해질 수 있으므로 1280/1440 화면의 패널 접기·배치 정책을 별도 확정해야 한다.
HTML의 폭 변경 옵션을 제품 정책으로 자동 채택하지 않는다.
